# Library Management System (DBMS Project)

This project is a database management system designed to handle basic library operations such as managing books, members, and transactions.

## Features
- Book management (add, update, delete, search)
- Member management
- Book issue and return tracking
- Availability status of books

## Database Design
- Created relational tables for books, members, and transactions
- Applied normalization to reduce redundancy and maintain data integrity
- Defined primary keys, foreign keys, and constraints

## SQL Operations
- Queries for issuing and returning books
- Tracking available and borrowed books
- Managing member records
- Ensuring consistency using constraints and triggers

## Tools & Technologies
- SQL  
- DBMS Concepts
